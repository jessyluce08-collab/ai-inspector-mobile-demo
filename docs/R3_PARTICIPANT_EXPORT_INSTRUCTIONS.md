# Conserver et remettre votre fichier — après autorisation du pilote

À la fin, touchez **Télécharger mes résultats**, puis vérifiez la présence du fichier `.json` dans Téléchargements sur Android ou Fichiers sur iPhone. La page indique qu’une demande a été faite ; elle ne garantit pas à elle seule que l’enregistrement a réussi.

Gardez l’onglet ouvert jusqu’à avoir retrouvé le fichier. Ne rafraîchissez pas la page : les réponses sont conservées uniquement dans cet onglet. Vous pouvez réessayer le téléchargement sans refaire la session. Si nécessaire, utilisez **Partager le fichier…** ou **Afficher le JSON si l’enregistrement échoue**. Ne modifiez pas le contenu du JSON.

Si vous arrêtez, **Arrêter et préparer un export partiel** permet de conserver ce qui existe déjà. Un fichier partiel est utile au bilan de faisabilité ; ne recommencez pas la tâche pour le remplacer.

Vous choisissez de remettre ou non le fichier, par le canal indiqué dans les informations du pilote. Rien n’est envoyé automatiquement. Ne remettez pas une capture d’écran à la place du JSON. Le fichier des réponses est distinct du diagnostic technique, demandé seulement en cas de difficulté et par une action volontaire.

Conservez votre code pseudonyme si vous souhaitez demander un retrait selon la politique annoncée. Aucune invitation ou participation n’est autorisée par cette seule notice.
